# Security policy

Please report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/thurahtetaung/virtual-tavern/security/advisories/new)
rather than opening a public issue.

Only the latest release is supported with security fixes.

## Scope

The admin password and the back-room password gate are the only access controls: rooms are unlisted,
but anyone with a room link can join a public game, so that is by design rather than a vulnerability.
