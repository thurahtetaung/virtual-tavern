# Short Fuse

Notes for working on this game. The repo-wide rules are in the root `CLAUDE.md`, including the shared patterns every back-room game follows; this file lists only what this game adds or does differently. Update this file in the same change as any rule, id or asset change.

## Rules and boundaries

- **Short Fuse** (`packages/private-games/short-fuse`, id `short-fuse`) is a bomb-card game for 2 to 10: play cards, then draw one; a drawn Bomb explodes you unless you Defuse it and hide it back; the last one standing wins. Classic, Adult and Party decks, Expansions 1–4 (host toggles `x2`, `x3`, `x4`), Zombie and Chaos presets.
  - **Ids:** neutral card ids (`bomb`, `defuse`, `attack`, `nope`, `cat1`…`cat5`, `void`…; `src/logic/cards.ts`), and every card instance has a random 8-character id that says nothing about it. Text uses name tokens (`{c:attack}`, `{bomb}`); `private-assets/tools/short-fuse-manifest.py` builds the manifest. Deck sizes per player count are in `deck.ts`, tested against the printed piles.
  - **The Nope window:** every play (not draws, Bombs or Defuse) waits out one fixed countdown (`nopeSeconds`, 4 s) everyone sees; only holders get the button (`canNope`), it never ends early, a Nope restarts it, and a late Nope, one inside 800 ms of the last or one naming an old `window` id is refused without spending the card. The window resolves in `onDeadline`, with randomness from the hidden seed.
  - **Surprises:** a blindfolded hand (`blind`) is face down and reshuffled on every change, so its owner acts by slot; a held Bomb goes off if the Shelter leaves; ghosts (Expansion 4) keep their hand and Vault, take no turns, can't be targeted, and may play Nope and NOW cards; a Second Life is never Noped and must bring back a ghost if there is one. The rulings are in `cursed.test.ts` and `ghosts.test.ts`.
  - **`view()`:** the pile is only `count`, `bombsOut` and the face-up Black Hole's edge; peeks, placements and swapped cards only in their owner's `memory`; at the end, where each Bomb was hidden.
  - **Testing:** `SHORT_FUSE_TEST_RIG=1` lets the host fix the next game's hands and pile from a lobby panel.
  - **Wide screens:** the draw and discard piles size by the window's height (80 px on a 720 px laptop up to 128 px), and your move (Play and Draw, targets, the blindfold and NOW docks) sits between the piles like the Nope countdown, so nothing covers the hand; phones keep it in the fixed bar. At the end the winner's hand is sized by the end's fit (`--vt-fit`), so Play again stays in view.

## Assets

**Short Fuse** (`node scripts/r2-upload.mjs short-fuse <folder>`, dry-run first; the folder is what `private-assets/tools/short-fuse-manifest.py` prepares): `cards/<face>.webp` (400×560), `cards/thumb/<face>.webp` (180×252, the same names), `cards/back.webp`, and a `manifest.json` of the form `{ "title": "…", "back": "cards/back.webp", "thumbs": "cards/thumb/", "names": { "cards": { "<card id>": "…" }, "adultCards": { "cat1": "…", … }, "sets": { "classic", "adult", "party", "x1", "x2", "x3", "x4" }, "bomb": "…", "bombs": "…" }, "faces": { "<card id>": { "classic": ["cards/….webp", …], "adult": […] } }, "text": { "cards/….webp": { "flavour", "rules" } }, "extras": { "crownIcon": "extras/….webp" } (the Vault's crown on its wearer's seat), "credit": { "title", "paragraphs": […], "links": [{ "label", "href" }] } }` (shape in `packages/private-games/short-fuse/src/logic/manifest.ts`; card ids such as `bomb`, `defuse`, `peek3`, `cat1`, `void`, and the fourth expansion's `revive`, `dig`, `ghostattack`, `feed`, `copy`, `seer`, `robber`, `shufflenow`, are in `src/logic/cards.ts`). Every field is optional: without it the cards are drawn as placeholders (Bomb, Defuse, Cat A…). Copies of a card cycle through its faces; `adult` faces and names are used when the host picks the 18+ deck, and fall back to the classic ones. The credit shows in the guide footer. Once it is uploaded, set the title with the `short-fuse` id.
