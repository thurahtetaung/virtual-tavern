# Hydra

Notes for working on this game. The repo-wide rules are in the root `CLAUDE.md`, including the shared patterns every back-room game follows; this file lists only what this game adds or does differently. Update this file in the same change as any rule, id or asset change.

## Rules and boundaries

- **Hydra** (`packages/private-games/hydra`) is a hidden-role election game for 5 to 10 (blue team against the red team and its Leader). Its package is **CC BY-NC-SA 4.0** (`"license"` and `NOTICE`), unlike the rest of the repo. Never write the commercial game's team, role or ballot words either.
  - **Words:** teams and policies are `blue`/`red`, the special role `leader`, ballots `yes`/`no`. No player-facing text spells out an office, card or team: it uses name tokens (`{blue}`, `{leader}`, `{president}`, `{chancellor}`, `{policy}`…, capitalised for a sentence start; "a {x}" becomes "an" before a vowel, `src/logic/names.ts`), filled from the manifest's `names`; every status line, prompt and notice is a key in `src/logic/copy.ts`, which a manifest may reword, and refusals go through `useRefusalWording`. Stats and recaps use `{role:…}` placeholders filled by `placeholderWord`. `src/ui/terms.test.ts` and `terms.test.ts` scan for stray words. The guide is named through the web registry's `namedGuide` hook, which adds the original's credit as its `footer`.
  - **Rules (the owner's rulings):** the tracker resets only on an enacted policy; a vetoed pair becomes the last elected government; the Chancellor's two cards are shuffled (`session.shuffled`); claims are mandatory and final (`claim` stage after each session; only the host skips a missing one once the soft claim timer is up); strict timers leave a missing vote uncounted (majority of votes cast) and play other turns at random, never claims. Votes stay hidden and changeable until the last is in.
  - **`view()`:** your own role and what it knows, hands only to their holders, investigation and peek memories only to their owner, roles and the truth log only at the end. Claim flags (`claims.ts`) use public information only. No bot.
  - **Layout:** on phones tall enough (800 px+) with six players or fewer, both boards stack at full width; otherwise they swipe one at a time. On desktops the Timeline leads the rail, which fits the window and scrolls inside.
  - **Testing:** `HYDRA_TEST_DECK` (a string of `b`/`r`) stacks the top of every new deck.

## Assets

**Hydra** (`node scripts/r2-upload.mjs hydra <folder>`, dry-run first; the folder is what `private-assets/tools/hydra-cut.py` writes): `roles/{leader,red-0..2,blue-0..5,back}.webp`, `party/{blue,red,back}.webp`, `policy/{blue,red,back}.webp`, `ballot/{yes,no,back}.webp`, `boards/{blue,small,medium,large}.webp` (the playing half of each board; the slot positions the UI lays cards on are in `packages/private-games/hydra/src/ui/Boards.tsx`), `powers/{investigate,special,peek,execute,win}.webp`, `badges/{president,chancellor,cleared}.webp`, and a `manifest.json` of the form `{ "title": "…", "names": { "blue", "blues", "red", "reds", "leader", "yes", "no" }, "art": { "roles": { "blue": […], "red": […], "leader": […], "back" }, "party": {…}, "policy": {…}, "ballot": {…}, "boards": {…}, "powers": {…}, "badges": {…} }, "powers": { "<power>": { "name", "text" } }, "guide": { "tagline" }, "credit": { "title", "game", "designers", "publisher", "link", "licence": { "name", "url" }, "text", "changes": […] } }` (shape in `packages/private-games/hydra/src/logic/manifest.ts`). Every field is optional: without it the teams read Loyalists / Conspirators / the Usurper, ballots Yes / No, and the cards and boards are drawn in CSS. The credit block is the original game's licence attribution: it shows in the guide footer, the lobby, the Me tab and the end screen. Once it is uploaded, set the game's title (next step) with the `hydra` id. Hydra's manifest may also name the offices and cards (`names.president`, `chancellor`, `candidate`, `presidentShort`, `chancellorShort`, `policy`, `policies`, `party`, `veto`, `bluePolicy`, `redPolicy`, all defaulting to Hydra's own words) and supply the optional fields its themed edition uses (next item).
