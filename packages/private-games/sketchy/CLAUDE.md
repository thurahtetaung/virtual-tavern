# Sketchy

Notes for working on this game. The repo-wide rules are in the root `CLAUDE.md`, including the shared patterns every back-room game follows; this file lists only what this game adds or does differently. Update this file in the same change as any rule, id or asset change.

## Rules and boundaries

- **Sketchy** (`packages/private-games/sketchy`, id `sketchy`) is a drawing and fake-title game for 3 to 8 (room 20): everyone draws a secret prompt, each drawing comes up for everyone but its artist to write a fake title, everyone picks the real one and likes the funny ones, and the reveal turns the picked fakes over with the truth last. Never write any of the original's games or characters either.
  - **Content packs** (`prompts`, `decoys`, `src/logic/content.ts`): every enabled prompts pack is a lobby toggle (kept in state); adult prompts only with the room's Adult switch; a pack whose every prompt has `{player}` is friend mode, off by default. Everything on the board is lowercased so the real title never stands out. The board is padded with house titles that score for nobody; a lie matching the real title under `wordKey`/`looseKey` is refused privately.
  - **`view()`:** your own prompt only while drawing; who drew the drawing on the table and its real title only to its artist until the reveal (the waiting-on chips name the missing only once someone else is in, so they never point at the artist); lies anonymous, picks and likes only as counts until the reveal; the pool and house titles never leave the server.
  - **Show and sound:** the second show-layer game. Moments come from the view on the server clock (`GameView.since`) or, for what the view doesn't time, from when the device first saw it (`useSeen`, `seenKeys`). The reveal uses the shared `revealMoments` (`@vt/game-sdk/show`, blocks in `@vt/ui/show`). Clip keys route sound in `audio.ts` (`me:` personal cues, `voice:` narrator, `joke:` matched by `jokeKey`).
  - **Phone layout:** Play / Scores on the room's tab bar; the drawing pad's Send, the fake title's Send and the host's Next drawing sit in the sticky bar with their refusals; the play area fits the screen and scrolls inside when it must (`FitArea`).
  - **Testing:** `SKETCHY_TEST_RIG=1` deals prompts in pack order and brings drawings up in seat order. Bots write fakes from unseen prompts of the room's packs (`BotCtx.contentPacks`, read on the server, never in a view).

## Assets

**Sketchy** (optional, `node scripts/r2-upload.mjs sketchy <folder>`): a `manifest.json` with `credit` (`{ "text": "…", "url": "https://…" }`, the guide's credits) and, for the show, `show` (`{ stage: { rig, phases: { lobby, draw, turn, end }, extras: { owl, cup, arm, catpaw } }, phone: { rig, phases: { turn } } }`, every phase listing its files under `show/`), `audio` (`music`, `sfx` and `voice` keys to lists of files, `durations` in ms and `text` per voice file; keys in `packages/private-games/sketchy/src/ui/audio.ts` and `show.ts`, personal cues as `me.<key>`) and `jokes` (a prompt's `jokeKey` to its joke file). Without them the table screen shows plain words and the game is silent. Its prompts and house titles are content packs, imported separately (Day to day). Once it is live, set the title with the `sketchy` id. To add the show's files to a live manifest, download the live `manifest.json`, merge in `show`, `audio` and `jokes`, dry-run the upload, upload only the new keys and check each object.
