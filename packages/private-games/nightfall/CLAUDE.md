# Nightfall

Notes for working on this game. The repo-wide rules are in the root `CLAUDE.md`, including the shared patterns every back-room game follows; this file lists only what this game adds or does differently. Update this file in the same change as any rule, id or asset change.

## Rules and boundaries

- **Nightfall** (`packages/private-games/nightfall`) is a one-night hidden-role game covering every set of its line (`ENABLED_SETS`). Never write its narrator app's name either. Roles, sets and artifacts are kebab-case ids (`seer`, `alpha-wolf`, `bonus1`, `claw-of-the-werewolf`).
  - **Engine:** `roles.ts` is the data registry (set, team, box count, how the Doppelgänger copies it), `plan.ts` the wake order (`STEPS`, sorted by the narrator's codes) and narration keys, `night.ts` each role's action (`begin`/`prompt`/`act`), `resolve.ts` the vote and win rules. `stage` is `ready`, `night`, `day`, `vote`, `reveal`; insights all come at the reveal.
  - **Night security:** every selected role gets a step of the same length whether its card is held or in the centre: its time to act (complex roles double), plus, with narration on and clip `durations` known, everything the narrator says in it (`narratedStepMs` in `narration.ts`, from line lengths read through `ctx.content.narrationLengths` and kept in `round.lengths`); the Oracle's step adds `ORACLE_REPLY_MS`, and her reply (random when she hasn't answered or her card is in the centre) comes at a fixed `night.replyAt`. Steps never wait, and `onDeadline` makes mandatory choices at random. Players act as their dealt role. A non-acting player's `view()` changes only in the step counter, its start and deadline and the step's public `pick` (tested); a tap on the shoulder arrives at daybreak, and the timeline is only revealed at the end.
  - **Alien set:** the narrator's random instructions are weighted tables in `src/logic/tables.ts`, drawn from the seeded rng and overridable per room (`Settings.weights`). Players are numbered by seat (`playersIn`). Picks are said out loud for everyone (the narrator is in the room), as the public `night.pick` and its cue, but never who acts, the centre cards, or whether the Oracle forced the aliens' swap; the Oracle's own answers stay private. Ripples, Nostradamus's team, the Blob and the Oracle's public answers are `announcements`, the same for every viewer. A time loop or a repeat grows `night.plan`, which every device rebuilds with `publicPlan`.
  - **Marks (Vampire set):** with any Vampire-set role but the Copycat (`MARK_ROLES`), every player gets a Mark of Clarity at the deal (`round.marks`, per player, not per card). Steps with negative `order` are the dusk: Fear (`feared`) only stops wakes from `NIGHT_ORDER` on. Marks reach `view()` only through the viewer's own notes until the reveal (tested). The vampires' Mark is one joint choice (the first pick counts for all). `resolveVote` takes the Marks into account.
  - **Sound:** narration Off / Host's device / Every device, plus music; `src/ui/audio.ts` is the pure scheduling (cues on the server clock, ducking, crossfades) and `useSound.ts` plays it after a user gesture. A close is timed to end just before its step (`fitCues`), cues queue, and a clip that would run more than `OVERRUN_MS` past its step is dropped (never a step's wake line). Text narration always shows.

- **UI:** Role-count controls are 44 px in wider role tiles; timing and narration selections use the shared accent treatment. Wide screens show the roles in play beside your card while players get ready. Role chips get a 44 px tap band on touch. The sound button in play is labelled Sound. The finale's winner cards size by how many won (one or two: 112 px phones, 192 px wide).

## Assets

**Nightfall** (`node scripts/r2-upload.mjs nightfall <folder>`, dry-run first): the folder holds `roles/<role-id>.webp` portraits, `audio/*.ogg` narration clips, `music/*.ogg` background tracks and a `manifest.json` of the form `{ "sets": { "<set>": { "name": "…", "roles": […], "artifacts": […] } }, "roles": { "<role-id>": { "name": "…", "text": "…", "art": "roles/<id>.webp" } }, "artifacts": { "<id>": { "name": "…", "text": "…" } }, "narration": { "<step>:wake": ["audio/….ogg"], "<step>:close": […], "night:start": […], … }, "durations": { "audio/….ogg": 2350 }, "music": { "lobby" | "night" | "day" | "vote" | "reveal": ["music/….ogg"] }, "musicTracks": { "<id>": { "name": "…", "file": "music/….ogg", "duration": 42.1 } } }`. Role ids are the plain words in `packages/private-games/nightfall/src/logic/roles.ts` (set ids `base`, `daybreak`, `bonus1`, `bonus2`, `vampire`…), and the Vampire set's Marks come from `"marks": { "<mark id>": { "name", "text", "art": "marks/<id>.webp" } }` and the Most Votes tokens from `"tokens": { "most-votes-1" | "most-votes-2": { "art": … } }`; narration keys follow `stepLines` in `plan.ts` (`seer:wake`, `doppelganger:insomniac:wake`, `werewolf:wake:dream-wolf`…). `durations` gives each clip's length in ms: with narration on, every night step lasts its time to act plus what the narrator says in it (the server re-reads the manifest every 10 minutes; without durations, steps keep their plain length). Every field is optional: without the manifest, roles show as styled placeholders and the game is silent. On `/tavern-keeper/games`, Nightfall's **Music** picks the tracks per phase (with previews) once the manifest is uploaded. The `lobby` tracks play while getting ready; the lobby itself plays no music.
